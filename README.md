# Deal Intelligence Agent

An agent that remembers every objection, stakeholder and promise across a
deal's calls, briefs the rep before the next call, drafts a personalized
follow-up email, and learns which objection handling wins across deals.
Memory is powered by Hindsight.

See CONTRACT.md for the API and docs/architecture.png for the design.
